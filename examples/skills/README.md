# Editable Task Packages

These are portable examples of task-owned code, not built-in task types or platform routing rules.
Each directory contains the complete workflow, manifest and deterministic synthetic tests.
No personal messages, credentials or account IDs are included.

- `unanswered`: batch-read the last physical message in each private conversation.
- `internships`: semantic and keyword recall, contextual extraction and native tool-calling follow-up.

The application stores independent copies in task instances. Editing these files does not
automatically replace a user's saved package. Saved changes must pass isolated validation.
`PLATFORM_API.md` is attached from the current platform contract when installing a package.
